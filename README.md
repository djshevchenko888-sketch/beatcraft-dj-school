# BEATCRAFT DJ Academy

Русскоязычная адаптивная учебная платформа по диджеингу.

## Возможности
- Шесть текстовых уроков с практикой и самопроверкой.
- Прогресс в localStorage (в пределах текущего браузера).
- TAP tempo и звуковой метроном на Web Audio API.
- Словарь терминов.

## Запуск
Откройте `dist/index.html` или запустите любой статический HTTP-сервер с корнем `dist`.
Зависимости и сборка не требуются. Для публикации загрузите содержимое `dist` на статический хостинг.

## Структура
- `dist/index.html` — интерфейс
- `dist/style.css` — адаптивные стили
- `dist/app.js` — уроки, прогресс и аудиопрактика

Сайт не собирает заявки, не принимает оплату и не содержит серверной авторизации. Прогресс не синхронизируется между устройствами.
